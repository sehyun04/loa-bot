2. 인식

전처리 값을 바꿔가며 아래 미리보기가 가장 또렷할 때 인식하세요

가공 화면처럼 항목이 가로로 늘어선 화면은, 평문만 보면 이름 줄과 값 줄이 따로 뭉쳐서 어떤 값이 어떤 항목의 것인지 알 수 없습니다. "열 자동 재구성"을 켜면 단어 위치 정보로 이름과 값을 다시 짝지어 줍니다. 세로로 나열된 일반 툴팁에서는 자동으로 평문 처리됩니다.

2.0x 에서는 "Lv." 가 "1." 로 오독되는 일이 잦습니다. 측정상 3.0x 부터 안정적입니다.
